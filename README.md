# Dashboard UAPI — AETN
## Reporte de Consistencia de Dictamen
### Distribuidora de Electricidad ENDE DEORURO S.A. | Gestión 2025

Dashboard web institucional de la **Unidad de Auditorías Preventivas (UAPI)** de la **Autoridad de Fiscalización de Electricidad y Tecnología Nuclear (AETN)**.

Evalúa la coherencia entre los valores numéricos de los indicadores de eficiencia y eficacia y las interpretaciones emitidas por la consultora **Delta Consult Ltda.**, en cumplimiento de la **Resolución AETN N° 298/2022**.

## Cómo publicar en GitHub Pages

1. Crea un repositorio nuevo en [github.com](https://github.com) (puede ser público o privado con GitHub Pro)
2. Sube los archivos `index.html` y `README.md`
3. Ve a **Settings → Pages**
4. En **Source** selecciona `Deploy from a branch`
5. Selecciona la rama `main` y carpeta `/ (root)`
6. Haz clic en **Save**
7. En unos minutos el dashboard estará disponible en `https://TU-USUARIO.github.io/NOMBRE-REPO`
